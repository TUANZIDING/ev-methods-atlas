## 哪些是真实的，哪些是示意

| 元素 | 性质 |
| --- | --- |
| 每个蛋白的原子坐标与形状 | 真实（实验结构） |
| 图集中各蛋白之间的相对大小 | 真实（统一比例尺 1.9 像素/Å） |
| 颜色、光照、描边 | 风格化（Goodsell 式），无数据含义 |
| EV 直径 80 nm、双层厚度约 4 nm | 典型数量级，示意 |
| 脂质 | 粗粒化小球，示意 |
| 膜蛋白与腔内蛋白的拷贝数、位置、取向；跨膜区段的定位 | 示意；跨膜残基范围为近似值，只用于把跨膜束放进膜内 |
| SEC 动画中颗粒速度与出峰位置 | 示意；逻辑依据 Böing 2014 与 Karimi 2018 |
| 回收率 × 特异性网格中各方法的位置 | 定性示意，依据 MISEV2018 的分类 |
